HTML TAGS

< !__ __ >

This tag is used to apply comment in an HTML document.

< !DOCTYPE >

This tag is used to specify the version of HTML

< a >

It is termed as anchor tag and it creates a hyperlink or link.

< abbr >

This tag is used to define an abbreviation.

< address >

This tag is used to define the contact information of the author or owner of a document.

< area >

This tag is used to define a clickable area inside an image map.

< article >

This tag is used to define an independent piece of content in a document.

< aside >

This tag is used to define content that is related to the main content but is not part of it.

< audio >

This tag is used to embed sound content in a document.

< b >

This tag is used to define bold text.

< base >

This tag is used to specify a base URL for all relative URLs in a document.

< bdi >

This tag is used to isolate a part of text that may be formatted in a different direction from the surrounding text.

< bdo >

This tag is used to override the current text direction.

< blockquote >

This tag is used to define a section that is quoted from another source.

< body >

This tag is used to define the main content of an HTML document.

< br >

This tag is used to insert a line break in a document.

< button >

This tag is used to create a clickable button.

< canvas >

This tag is used to draw graphics on the fly using JavaScript.

< caption >

This tag is used to define a title or caption for a table.

< cite >

This tag is used to define the title of a work.

< code >

This tag is used to define a piece of computer code.

< col >

This tag is used to define a column in a table.

< colgroup >

This tag is used to group a set of columns in a table.

< data >

This tag is used to link a piece of content with a machine-readable translation.

< datalist >

This tag is used to provide a list of predefined options for an input element.

< dd >

This tag is used to define a description of a term in a description list.
