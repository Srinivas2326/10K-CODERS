What is Internet?

=>The Internet is a global network of interconnected computers and servers that communicate with each other using standardized protocols.
=>It enables the exchange of information, data, and resources across vast distances, allowing users to access websites, send emails, stream media, and engage in various online activities.

What is Browser?

=>A web browser is a software application that allows users to access and view content on the World Wide Web.
Example: Google Chrome, Edge, Firefox

What is HTTP?

=>HTTP (Hypertext Transfer Protocol) is the foundation of data communication on the World Wide Web.
=>It defines how messages are formatted and transmitted, enabling web browsers to request and receive resources from web servers.
Example:http://192.168.103.108:5000/

What is HTTPS?

=>HTTPS (Hypertext Transfer Protocol Secure) is an extension of HTTP that adds a layer of security by encrypting the data exchanged between a web browser and a web server.
=>It uses SSL/TLS protocols to ensure secure communication, protecting sensitive information from eavesdropping and tampering.
Example: https://lightpdf.com/word-to-pdf

What is Website

=>A website is a collection of related web pages and multimedia content that is hosted on a web server and accessible via the Internet.
=>Websites can serve various purposes, such as providing information, offering services, or facilitating online transactions.
Example: www.google.com

What is web App?

=>A web application (web app) is a software application that runs on a web server and is accessed through a web browser.
=>Web apps can perform various functions, such as data processing, user interaction, and content management, and they often rely on server-side technologies to deliver dynamic content.
Example: www.facebook.com

What is Domain?

=>A domain is a human-readable address that identifies a specific location on the Internet, allowing users to access websites and web applications.
=>Domains are organized in a hierarchical structure, with top-level domains (TLDs) such as .com, .org, and .net.
Example: www.google.com

Types of Domains

=>There are several types of domains, including:
=>1. Top-Level Domains (TLDs): The highest level in the domain name hierarchy, such as .com, .org, and .net.
=>2. Second-Level Domains (SLDs): The part of the domain name that comes before the TLD, often representing the organization or entity.
=>3. Subdomains: Additional divisions of a domain that can be used to organize content or services within a website.
Example: www.google.com
www = Sub Domain
google = Main Domain
.com = Top Level Domain

What is IP address?

=>An IP address (Internet Protocol address) is a unique numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.
=>IP addresses serve two main functions: identifying the host or network interface and providing the location of the device in the network.
Example:192.168.1.105

What is the difference between Markup Language and Programming Language?

=>Markup languages are designed to annotate and format text, while programming languages are used to create algorithms and perform computations.
=>Markup languages focus on the presentation and structure of content, whereas programming languages emphasize logic and functionality.
Example: HTML is a markup language, while Python is a programming language.
