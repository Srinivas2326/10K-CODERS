HTML TAGS

TAG NAME DESCRIPTION
  < !-- -- >   This tag is used to apply comment in an HTML document.
  < !DOCTYPE >   This tag is used to specify the version of HTML.
A
  < a >   It is termed as anchor tag and it creates a hyperlink or link.
  < abbr >   This tag is used to define an abbreviation.
  < address >   This tag is used to define the contact information of the author or owner of a document.
  < area >   This tag is used to define a clickable area inside an image map.
  < article >   This tag is used to define an independent piece of content in a document.
  < aside >   This tag is used to define content that is related to the main content but is not part of it.
  < audio >   This tag is used to embed sound content in a document.
B
  < b >   This tag is used to define bold text.
  < base >   This tag is used to specify a base URL for all relative URLs in a document.
  < bdi >   This tag is used to isolate a part of text that may be formatted in a different direction from the surrounding text.
  < bdo >   This tag is used to override the current text direction.
  < blockquote >   This tag is used to define a section that is quoted from another source.
  < body >   This tag is used to define the main content of an HTML document.
  < br >   This tag is used to insert a line break in a document.
  < button >   This tag is used to create a clickable button.
C
  < canvas >   This tag is used to draw graphics on the fly using JavaScript.
  < caption >   This tag is used to define a title or caption for a table.
  < cite >   This tag is used to define the title of a work.
  < code >   This tag is used to define a piece of computer code.
  < col >   This tag is used to define a column in a table.
  < colgroup >   This tag is used to group a set of columns in a table.
  < command >   This tag is used to define a command that the user can invoke.
D
  < datalist >   This tag is used to provide an autocomplete feature on input fields.
  < dd >   This tag is used to define a description of a term in a description list.
  < del >   This tag is used to define text that has been deleted from a document.
  < details >   This tag is used to create a disclosure widget from which the user can obtain additional information or controls.
  < dfn >   This tag is used to define a term that is being defined within the content.
  < dialog >   This tag is used to define a dialog box or other interactive component.
  < div >   This tag is used to define a division or section in a document.
  < dl >   This tag is used to define a description list.
  < dt >   This tag is used to define a term in a description list.
E
  < em >   This tag is used to define emphasized text.
  < embed >   This tag is used to embed external content, such as multimedia.
F
  < fieldset >   This tag is used to group related elements in a form.
  < figcaption >   This tag is used to define a caption for a element.
  < figure >   This tag is used to represent self-contained content, such as illustrations or diagrams.
  < footer >   This tag is used to define a footer for a document or section.
  < form >   This tag is used to create an HTML form for user input.
H
  < h1 >   This tag is used to define the most important heading in a document.
  < h2 >   This tag is used to define the second most important heading in a document.
  < h3 >   This tag is used to define the third most important heading in a document.
  < h4 >   This tag is used to define the fourth most important heading in a document.
  < h5 >   This tag is used to define the fifth most important heading in a document.
  < h6 >   This tag is used to define the sixth most important heading in a document.
  < head >   This tag is used to define the head section of a document.
  < header >   This tag is used to define a header for a document or section.
  < hgroup >   This tag is used to group a set of elements.
  < hr >   This tag is used to create a thematic break in a document.
I
  < i >   This tag is used to define italic text.
  < iframe >   This tag is used to define an inline frame.
  < img >   This tag is used to embed an image in a document.
  < input >   This tag is used to create an input field in a form.
  < ins >   This tag is used to define text that has been inserted into a document.
  < kbd >   This tag is used to define keyboard input.
L
  < label >   This tag is used to define a label for an input element.
  < legend >   This tag is used to define a caption for a
element.
  < li >   This tag is used to define a list item.
  < link >   This tag is used to define the relationship between a document and an external resource.
M
  < main >   This tag is used to define the main content of a document.
  < map >   This tag is used to define an image map.
  < mark >   This tag is used to define highlighted text.
  < meta >   This tag is used to define metadata about an HTML document.
  < meter >   This tag is used to define a scalar measurement within a known range.
N
  < nav >   This tag is used to define navigation links.
  < noscript >   This tag is used to define an alternate content for users that have disabled scripts in their browser.
O
  < object >   This tag is used to embed multimedia content in a document.
  < ol >   This tag is used to define an ordered list.
  < optgroup >   This tag is used to group related options in a drop-down list.
  < option >   This tag is used to define an option in a drop-down list.
  < output >   This tag is used to define the result of a calculation.
P
  < p >   This tag is used to define a paragraph.
  < param >   This tag is used to define parameters for an object.
  < picture >   This tag is used to define a container for multiple image sources.
  < pre >   This tag is used to define preformatted text.
  < progress >   This tag is used to define a progress bar.
Q
  < q >   This tag is used to define a short inline quotation.
R
  < rp >   This tag is used to define what to show in browsers that do not support ruby annotations.
  < rt >   This tag is used to define the ruby text component of a ruby annotation.
  < ruby >   This tag is used to define a ruby annotation.
S
  < s >   This tag is used to define text that is no longer correct.
  < samp >   This tag is used to define sample output from a computer program.
  < samp >   Sample output from a program.
  < section >   Defines a document section.
  < select >   Defines a drop-down list.
  < small >   Defines smaller text.
  < source >   Defines multiple media resources for elements such as
  < span >   Defines a section in a document.
  < strong >   Defines important text.
  < strike >   Strikethrough text. (Deprecated)
  < sub >   Subscript text.
  < summary >   Defines a summary for a
element.
  < sup >   Superscript text.
T
  < table >   Defines a table.
  < tbody >   Groups the body content in a table.
  < td >   Defines a cell in a table.
  < template >   Defines a template.
  < textarea >   Defines a multi-line text input control.
  < tfoot >   Groups the footer content in a table.
  < th >   Defines a header cell in a table.
  < thead >   Groups the header content in a table.
  < time >   Defines a specific time (or range of time).
  < title >   Defines a title for the document.
  < tr >   Defines a row in a table.
  < track >   Defines text tracks for and elements.
U
  < u >   Defines text that should be stylistically different from normal text.
  < ul >   Defines an unordered list.
V
  < var >   Defines a variable.
  < video >   Defines a video or movie.
  < wbr >   Defines a possible line-break.
W
  < wbr >   Defines a possible line-break.
  < webview >   Defines a webview.
